Files:

- assets/highline-logo.jpg: the supplied institute logo

Preview locally:
Open index.html in a browser. The hero background uses a remote Unsplash image and requires internet.

Deploy to Vercel using GitHub:
1. Create a GitHub repository named highline-fire-safety-website.
2. Upload index.html and the assets folder (keep the folder structure).
3. In Vercel, choose Add New > Project, import that repository and deploy.
4. Preview the vercel.app address and test the contact/enquiry links.
5. Add highlinefireandsafety.in and www.highlinefireandsafety.in in the Vercel project Domains settings.
6. In the current DNS provider (nameservers were detected as Bluehost), change only the website records based on the exact values Vercel shows. Do not remove MX/TXT/email records or change nameservers unless you have confirmed the email setup.

The WhatsApp enquiry button opens WhatsApp to 8121118000 with a pre-filled message. Verify all course/approval claims and details before publishing.
